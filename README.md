# ذكّر | Dhakkir

تطبيق ويب (React) للأذكار والأدعية اليومية والأحاديث النبوية، بواجهة عربية أصلية (RTL) مع دعم للإنجليزية والألمانية.

> ⚠️ **حالة المشروع حاليًا: لا يعمل (Build فاشل).** انظر البند الأول في [`TODO.md`](./TODO.md) قبل أي تطوير.

## نظرة عامة

- **الأذكار (Adhkar):** 18 تصنيفًا (أذكار الصباح، المساء، النوم، الاستيقاظ، الصلاة، الوضوء، الخروج من المنزل، دخوله، المسجد، الطعام، السفر، الهم والكرب، المرض، الباقيات الصالحات، أدعية نبوية، دعاء الاختبار، أذكار متنوعة)، مع عدّاد تكرار تفاعلي (tap counter) وتتبّع "تم الإنجاز" لكل ذكر.
- **الأحاديث النبوية (Hadiths):** 10 تصنيفات أخلاقية وفقهية (الأخلاق، المعاملة، الرحمة والرفق، الصدق والأمانة، الصبر والشكر، الأسرة والجيران، العلم والحكمة، المال والعمل، الآداب العامة، الإنفاق والصدقات)، مع النص العربي والترجمة الصوتية (transliteration) والترجمة والمصدر والراوي.
- **تعدد اللغات:** عربي / إنجليزي / ألماني (`ar` / `en` / `de`) قابل للتبديل من الإعدادات.
- **شاشة افتتاحية (Splash)** بتأثير ظهور تدريجي، وشاشة إعدادات لاختيار اللغة وإظهار/إخفاء الترجمة.

## المكدس التقني (Tech Stack)

- [React 18](https://react.dev/) عبر [Create React App](https://create-react-app.dev/) (`react-scripts` 5)
- لا توجد مكتبة تنسيق خارجية — التنسيق بالكامل عبر inline `style` في JSX
- إعداد نشر جاهز على [Vercel](./vercel.json)

## بنية المشروع الحالية

```
.
├── App.jsx                 # بيانات الأذكار/الأحاديث + مكوّن الواجهة بالكامل (~1300 سطر)
├── index.html              # نقطة HTML — لكنها في الجذر وليست داخل public/ (❌ خطأ بنيوي)
├── index.js                # نقطة تشغيل React — لكنها في الجذر وليست داخل src/ (❌ خطأ بنيوي)
├── package.json
├── vercel.json
└── Dhakkir ذكّر .aab       # حزمة أندرويد مبنية (ثنائية، 3.2MB) — لا ينبغي تتبّعها في Git
```

`react-scripts` يفرض بنية ثابتة: `public/index.html` كنقطة HTML، و`src/index.js` كنقطة الدخول. بما أن الملفين موجودان في الجذر، فإن **البناء والتشغيل يفشلان حاليًا فعليًا** (تم التحقق: `npm run build` ⇒ `Could not find a required file. Name: index.html Searched in: public`). تفاصيل الإصلاح في `TODO.md`.

# ذكّر | Dhakkir

تطبيق ويب (React) للأذكار والأدعية اليومية والأحاديث النبوية، بواجهة عربية أصلية (RTL) مع دعم للإنجليزية والألمانية.

## نظرة عامة

- **الأذكار (Adhkar):** 18 تصنيفًا (أذكار الصباح، المساء، النوم، الاستيقاظ، الصلاة، الوضوء، الخروج من المنزل، دخوله، المسجد، الطعام، السفر، الهم والكرب، المرض، الباقيات الصالحات، أدعية نبوية، دعاء الاختبار، أذكار متنوعة)، مع عدّاد تكرار تفاعلي (tap counter) وتتبّع "تم الإنجاز" لكل ذكر — **يُحفظ تلقائيًا** ويُستعاد عند إعادة فتح التطبيق.
- **الأحاديث النبوية (Hadiths):** 10 تصنيفات أخلاقية وفقهية (الأخلاق، المعاملة، الرحمة والرفق، الصدق والأمانة، الصبر والشكر، الأسرة والجيران، العلم والحكمة، المال والعمل، الآداب العامة، الإنفاق والصدقات)، مع النص العربي والترجمة الصوتية (transliteration) والترجمة والمصدر والراوي.
- **تعدد اللغات:** عربي / إنجليزي / ألماني (`ar` / `en` / `de`) قابل للتبديل من الإعدادات، مع تبديل تلقائي لاتجاه الصفحة (RTL/LTR).
- **تذكيرات اختيارية:** يمكن تفعيل إشعارات المتصفح من الإعدادات لتذكيرك بأذكار الصباح والمساء والنوم والاستيقاظ في أوقاتها المقترحة (طالما التطبيق مفتوح في المتصفح — راجع القيود في `TODO.md`).
- **شاشة افتتاحية (Splash)** بتأثير ظهور تدريجي، وشاشة إعدادات لاختيار اللغة وإظهار/إخفاء الترجمة وتفعيل التذكيرات.

## المكدس التقني (Tech Stack)

- [React 18](https://react.dev/) عبر [Create React App](https://create-react-app.dev/) (`react-scripts` 5)
- لا توجد مكتبة تنسيق خارجية — التنسيق بالكامل عبر inline `style` في JSX
- `@testing-library/react` + Jest (مضمّنة عبر `react-scripts test`) للاختبارات
- إعداد نشر جاهز على [Vercel](./vercel.json)، وCI عبر GitHub Actions

## التشغيل محليًا

```bash
npm install
npm start        # بيئة التطوير على http://localhost:3000
npm test         # تشغيل الاختبارات
npm run build    # بناء نسخة الإنتاج في مجلد build/
```

## النشر

المشروع مهيّأ للنشر على Vercel عبر `vercel.json` (يبني بـ `npm run build` ويخرج مجلد `build`).

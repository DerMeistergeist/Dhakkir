# ذكّر | Dhakkir

تطبيق ويب (React) للأذكار والأدعية اليومية والأحاديث النبوية، بواجهة عربية أصلية (RTL) مع دعم للإنجليزية والألمانية.

## نظرة عامة

- **الأذكار (Adhkar):** 18 تصنيفًا (أذكار الصباح، المساء، النوم، الاستيقاظ، الصلاة، الوضوء، الخروج من المنزل، دخوله، المسجد، الطعام، السفر، الهم والكرب، المرض، الباقيات الصالحات، أدعية نبوية، دعاء الاختبار، أذكار متنوعة)، مع عدّاد تكرار تفاعلي (tap counter) وتتبّع "تم الإنجاز" لكل ذكر — **يُحفظ تلقائيًا** ويُستعاد عند إعادة فتح التطبيق.
- **الأحاديث النبوية (Hadiths):** 10 تصنيفات أخلاقية وفقهية (الأخلاق، المعاملة، الرحمة والرفق، الصدق والأمانة، الصبر والشكر، الأسرة والجيران، العلم والحكمة، المال والعمل، الآداب العامة، الإنفاق والصدقات)، مع النص العربي والترجمة الصوتية (transliteration) والترجمة والمصدر والراوي.
- **تعدد اللغات:** عربي / إنجليزي / ألماني (`ar` / `en` / `de`) قابل للتبديل من الإعدادات، مع تبديل تلقائي لاتجاه الصفحة (RTL/LTR).
- **القرآن الكريم (مصحف كامل):** تصفح المصحف بشكل صفحات حقيقية (604 صفحة، مطابقة لتخطيط مصحف مجمع الملك فهد المستخدم في أغلب المصاحف المطبوعة)، فهرس بالسور الـ114 مع الانتقال المباشر لبداية كل سورة، الانتقال لرقم صفحة معيّن، بحث نصي عن كلمة أو جزء آية (متسامح مع غياب التشكيل)، وحفظ آخر صفحة قُرئت تلقائيًا. النص والتخطيط محمّلان بالكامل offline بدون أي اتصال بخادم، ويُحمَّلان فقط عند فتح قسم القرآن (code-split) حتى لا يُبطئ تحميل بقية التطبيق. راجع قسم "الترخيص والمصادر" أدناه لمصدر بيانات النص.
- **مواعيد الصلاة (حساب فلكي):** تبويب جديد يحسب أوقات الفجر والشروق والظهر والعصر والمغرب والعشاء **على الجهاز مباشرة** بمعادلات فلكية قياسية (موضع الشمس/معادلة الزمن)، بناءً على موقعك الجغرافي (Geolocation API) — بلا أي اتصال بالإنترنت أو خادم خارجي. يدعم 5 طرق حساب شائعة (رابطة العالم الإسلامي، ISNA، الهيئة المصرية، أم القرى، جامعة كراتشي) ومذهبي العصر (الجمهور/حنفي)، قابلة للتغيير من الإعدادات. **ملاحظة:** الحساب يفترض أن توقيت جهازك مطابق لموقعك الجغرافي الفعلي (وهو ما ينطبق تلقائيًا عند استخدام تحديد الموقع من نفس الجهاز)، وقد تختلف النتائج ببضع دقائق عن الجداول الرسمية المحلية التي تضيف تعديلات يدوية.
- **تذكيرات اختيارية:** يمكن تفعيل إشعارات المتصفح من الإعدادات لتذكيرك بأذكار الصباح والمساء والنوم والاستيقاظ، وكذلك بمواعيد الصلاة الخمس إذا فُعِّل الموقع الجغرافي (طالما التطبيق مفتوح في المتصفح — راجع القيود في `TODO.md`).
- **شاشة افتتاحية (Splash)** بتأثير ظهور تدريجي، وشاشة إعدادات لاختيار اللغة وإظهار/إخفاء الترجمة وتفعيل التذكيرات.

## المكدس التقني (Tech Stack)

- [React 18](https://react.dev/) عبر [Create React App](https://create-react-app.dev/) (`react-scripts` 5)
- لا توجد مكتبة تنسيق خارجية — التنسيق بالكامل عبر inline `style` في JSX
- `@testing-library/react` + Jest (مضمّنة عبر `react-scripts test`) للاختبارات
- إعداد نشر جاهز على [Vercel](./vercel.json)، وCI عبر GitHub Actions

## التشغيل محليًا

```bash
npm install
npm start        # بيئة التطوير على http://localhost:3000
npm test         # تشغيل الاختبارات
npm run build    # بناء نسخة الإنتاج في مجلد build/
```

## الترخيص والمصادر

لا يوجد ملف ترخيص حاليًا. نصوص الأحاديث والأذكار تحتاج إلى مراجعة وتوثيق مصدرها (مثل حصن المسلم أو مراجع الحديث المعتمدة) للتحقق من دقة النسبة والتخريج.

بيانات القرآن الكريم (`src/data/quran/`) مولَّدة من مصدرين مفتوحين عبر `scripts/build-quran-data.js`، مع نسبة المصدر في أعلى كل ملف مُولَّد:
- **نص الآيات:** مشروع [quran-json](https://github.com/risan/quran-json) (رخصة CC-BY-4.0، بقلم Risan Bagja Pradana) — تم أخذ النص العربي فقط وإسقاط الترجمات والترجمة الصوتية.
- **تخطيط صفحات المصحف (604 صفحة):** مشروع [mushaf-engine](https://www.npmjs.com/package/@sahabaplus/mushaf-engine) (رخصة MIT) — بيانات تخطيط مصحف مجمع الملك فهد.

لإعادة توليد هذه البيانات (مثلًا بعد تحديث المصدر): `npm install --no-save @sahabaplus/mushaf-engine quran-json && node scripts/build-quran-data.js`.
